Free Live Hosting & Google Sheets Integration

How to Live Host this Website 100% Free?

Option 1: GitHub Pages (Recommended)

  1. Create a free account on GitHub.com.
  2. Create a new repository named aimim-akola-portal.
  3. Upload this file saved as index.html.
  4. Go to Settings > Pages → Select main branch → Click Save.
  5. Your portal is now live with a free SSL link (https://yourusername.github.io/aimim-akola-portal).

Option 2: Netlify Drag & Drop

Go to Netlify.com, register free, drag and drop the folder containing index.html and get a live shareable URL instantly.

Connecting Registration Data to Google Sheets

1. Open Google Sheets and create a sheet named AIMIM Registrations.

2. Go to Extensions > Apps Script and paste this code:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.regNum, data.fullName, data.contact, data.email, data.address, data.photo]);
  return ContentService.createTextOutput(JSON.stringify({"status":"success"})).setMimeType(ContentService.MimeType.JSON);
}

3. Click Deploy > New Deployment > Web App, select "Anyone" for access, copy the Web App URL, and paste it into the Connect Google Sheet setting above!
